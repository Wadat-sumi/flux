A single Azure Container App serves React and the Node API. Private PostgreSQL 16, managed identities, Key Vault, VNet/private DNS, logs and a separate administrative migration job are defined. GHCR stores the immutable OCI image. A manually dispatched GitHub Actions workflow runs the required tests, uses Buildah to build and Podman to smoke-test, and optionally publishes to GHCR. Your Mac needs Azure CLI/Terraform/Git, with no local container tool. Linux image build and GitHub publication still require verification.

Private GHCR pulls use a read-only package token stored only in Azure Key Vault. Container Apps/jobs use managed identities to resolve the vault reference; the token is not a Terraform input or data lookup. Public pulls are explicitly optional. Workflow publication uses GitHub's automatically minted job token, with no stored publishing key. Runtime and migration database credentials remain separate. Database provisioning still places sensitive database values in protected state. An Azure Blob backend with Entra authentication/locking is now declared and needs non-secret storage settings at init. Never commit state/plans/tfvars or print secret values.

The stages are automatic state-storage bootstrap → foundation → Portal secret entry → verified GHCR image → private database → migration-job creation/execution → application → HTTPS/live checks.
