# Flux data sources

All networks and demand are synthetic and created within this session. Coordinates, road lengths, demand rates, lane counts and signal times are illustrative defaults, not measurements of a real city. No OSM/geospatial dataset or personal travel trace is used. The seed and complete scenario JSON are sufficient to regenerate arrivals and rerun an experiment with the same software version.

IDM equations are based on the [model authors' public explanation](https://traffic-simulation.de/info/info_IDM.html). The implementation is original TypeScript, with simplified junction and lane policies described in the methodology. Design reference attribution is recorded in the design proposals; no third-party art, video, logo or source code is bundled.
